## 20:06 - WSL 代理配置

冲哥问 WSL 如何配置代理。搜索微软文档后发现：

- **推荐方案**：`autoProxy=true` 配置
- 在 Windows 用户主目录创建 `~/.wslconfig`，添加：
  ```ini
  [wsl2]
  autoProxy=true
  ```
- 作用：WSL 自动读取 Windows 系统的 HTTP 代理设置，Clash/V2Ray 等代理直接生效
- 需要执行 `wsl --shutdown` 重启 WSL 使配置生效
- 验证方式：在 WSL 中运行 `env | grep -i proxy`
